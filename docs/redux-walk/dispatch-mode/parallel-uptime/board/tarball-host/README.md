# tarball-host

## Purpose & Contents

This topic holds where the Trilium fork's release tarball lives. redux-build/trilium-fork raised it.

## Result

The tarball stays on mizar, the fork's home. The awm deploy pushes it to deneb over the mizar to deneb edge. deneb never fetches from mizar. The pin names the file and its sha256. Spec: install.md R115 "Gap from today".
