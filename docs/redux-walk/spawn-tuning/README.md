# spawn-tuning

## Purpose & Contents

This topic holds how a spawned agent's model and effort are chosen.

## Tony's words

> new agents spawned should have model and effort level tuned to task, with fable requireing user consent. no xHigh for any model

> spawning: high effort is the upper limit

> just asking is fine for fable since this is for dfs-interview where I will be present

## Result

1. Each spawn names a model and an effort that fit its task. `reflection start_other` requires both, with no default.
2. High is the upper limit. `start_other` refuses xhigh and max.
3. Fable needs Tony's consent. The coordinator asks him in the chat. No code gate.
