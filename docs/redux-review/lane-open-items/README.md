# lane-open-items

## Purpose & Contents

The open-for-Tony items that each implementer lane reported, and where the redux build plan resolves each one. The plan is the approved build plan of 2026-11-04 (tasks T1 to T30). The status table is `../build-survey.md`.

## Resolution

Each item is a build task. No item needed a new decision from Tony.

- **Trilium tool lane** (queue). T13 builds `note_create` with a `note_id`, and admits the operations home's edge identity for the note verbs inside the command-center subtree.
- **Tether lane push and pin bump** (channels). T11 prepares the release and the pin. T26 pushes the tether release, under the deploy permissions of the plan.
- **Persistent rooms end on a relay restart** (channels). T11 builds `channels.md` R72 item 5, with room state on deneb's disk and no plaintext of an encrypted room.
- **Relay limits, spake2 suite, tether verbs, isolated sessions without a channel** (channels). The relay limits stay as built. T1 made channel's install fail without spake2. T11 builds R111, a channel for an isolated session through its R9 id.
- **auth verbs, quay org** (plugins). auth serves its own `auth` tool, because each domain keeps one tool (T6, `install.md` R116 item 5). Test images go to `quay.io/hallamlab` (T19, R119). Tony's quay robot account is a manual step.
- **Python discovery root, isolated door port and ceiling list** (plugins). T19 removes the built-in root. T6 deletes the Python isolated door, and the ceiling comes from the manifests (R109 item 7).
- **Queue rest** (queue). T13 reads PROXY v2 on alcor's front, checks `order_pull` callers against the named node and fixes `AWM_TRILIUM_URL`. T2 and T9 carry the Chromium container. T18 closes the cutover gaps.
- **Harness rest** (harness). T12 adds the SessionStart-clear `harness_event` and R44 item 4, and moves the old state paths out of `.awm/` (R142). T6 has the gateway ask `reflection session_of` and builds R109 item 7.
- **`~/.claude` edits from the journal lane** (journal). T20 drafts them under `docs/redux/drafts/claude-home/`. T27 installs them on each node with the code they describe.
